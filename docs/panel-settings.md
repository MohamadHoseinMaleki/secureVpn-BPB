# تنظیمات پیشنهادی پنل برای ۱۰–۱۳ کانفیگ بهترین

## هدف
- تعداد کانفیگ حدود ۱۰ تا ۱۳ تا
- پینگ پایین
- کار روی همه نت‌ها (ایرانسل، همراه اول، رایتل، مخابرات و ...)

## تنظیمات Common
- Enabling IPv6 → **خاموش** (مگر اینکه مطمئنی همه نت‌ها IPv6 دارن)
- Local DNS: Google یا localhost
- Fake DNS: خاموش (مگر تست کردی)

## تنظیمات VLESS - Trojan
- Protocol: فقط **VLESS** فعال
- Ports: فقط `443` (+ حداکثر یکی دو تا پورت TLS دیگه اگر لازم بود)
- Clean IP/Domains: فقط ۳ تا ۵ تا بهترین IP (از اسکنر یا /proxy-ip تست latency بگیر)
- Proxy IP: ۱ تا ۳ تا Proxy IP با latency پایین
- Fingerprint: randomized یا chrome
- Best Interval: ۳۰ ثانیه

## بعد از Apply
سابسکریپشن رو کامل رفرش کن و تست کن.

با این تنظیمات معمولاً به محدوده ۱۰–۱۳ کانفیگ می‌رسی و Best Ping هم خودش بهترین رو انتخاب می‌کنه.
